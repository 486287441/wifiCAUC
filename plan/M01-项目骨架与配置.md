# M01 — 项目骨架与配置

**技术依据**：见 `plan/技术方案.md` §1–§2、§4.1。

## 目标

搭建可运行的 Python 包骨架、依赖清单、配置加载与示例模板，使后续模块有统一入口。

## 实现要点

1. 创建 `src/wificauc/` 包与 `requirements.txt`（`playwright`, `pyyaml`）。
2. `config.py`：从 `config.local.yaml` 加载；不存在时打印友好错误并指向 `config.example.yaml`。
3. 校验必填：`wifi.ssid`、`portal.url`、`credentials.username/password`、三个 selector。
4. `config.example.yaml` 与 PRD 门户字段一致（`DDDDD` / `upass` / `0MKKey`）。
5. 更新 `.gitignore`：`config.local.yaml`、`state/`、`.venv/`。
6. `main.py` 骨架：`once`（空实现打印「config ok」）、`run`/`resume`/`status` 占位。

## 验收标准

- [ ] `python -m venv .venv && pip install -r requirements.txt` 无报错。
- [ ] 复制 `config.example.yaml` → `config.local.yaml` 并填入测试账号后，`python -m wificauc.main once` 输出配置已加载（含 SSID、门户 URL，**不**打印密码）。
- [ ] 缺少 `config.local.yaml` 时退出码非 0，提示复制 example。
- [ ] 仓库中无真实密码文件被跟踪（`git status` 干净）。

## 操作步骤

### 第 1 步

创建目录结构、`requirements.txt`、`config.example.yaml`、`config.py`、`main.py` 占位命令。

### 第 2 步

编写 `README.md` 最小安装说明（venv、playwright install、复制配置）。

用户回复 **通过** 后进入 M02。
