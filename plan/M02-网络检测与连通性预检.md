# M02 — 网络检测与连通性预检

**技术依据**：见 `plan/技术方案.md` §4.3、§5（`on_wifi_connect`、`check_silent`）。

**依赖**：M01 完成。

## 目标

仅在连上 **CAUC-WIFI** 且**外网不可达**时，才进入后续门户登录。

## 实现要点

### `wifi.py`

- `get_current_ssid() -> str | None`：优先 `networksetup -getairportnetwork en0`（Wi‑Fi 接口名可配置）；解析失败返回 `None`。
- `is_target_wifi(ssid: str, target: str) -> bool`：trim、大小写敏感匹配配置中的 `wifi.ssid`。

### `connectivity.py`

- `is_internet_available(urls: list[str], portal_host: str) -> bool`：
  - 请求 captive 检测 URL（默认 Apple hotspot-detect）。
  - 若响应最终 URL 主机为 `192.168.4.252` 或 body 含门户特征 → 返回 `False`。
  - 若 Apple 页含 `Success` → 返回 `True`。

### `main.py` 集成

- `once` 流程：非目标 SSID → 打印 `skipped: wrong wifi` 退出 0。
- 目标 SSID 且外网可达 → 打印 `skipped: already online` 退出 0。
- 否则 → 打印 `need_portal_login`（M03 再接 Playwright）。

## 验收标准

- [ ] 未连 CAUC-WIFI 时，`once` 跳过且不启动浏览器。
- [ ] 已连 CAUC-WIFI 且能访问外网（如已登录）时，`once` 跳过、不打开 `192.168.4.252`。
- [ ] 已连 CAUC-WIFI 且外网不可达时，`once` 输出 `need_portal_login`（M03 前可手动验证日志即可）。
- [ ] 单元测试或脚本测试：mock SSID / mock HTTP 至少覆盖上述三种分支（可选最小 pytest）。

## 操作步骤

### 第 1 步

实现 `wifi.py`、`connectivity.py`。

### 第 2 步

接入 `main once`，在真实 CAUC-WIFI 环境下各测一次「已上网 / 未上网」。

用户回复 **通过** 后进入 M03。
