# M03 — 门户自动登录（Playwright）

**技术依据**：见 `plan/技术方案.md` §4.2、§5（门户字段、`never_click_only`、`headless`）。

**依赖**：M01、M02 完成。

## 目标

在无头浏览器中打开 ePortal，自动填表登录，并以「您已经成功登录」为成功判据；**绝不**点击注销。

## 实现要点

### `portal.py`

```python
async def login(config) -> LoginResult:
    # launch headless chromium
    # goto portal.url
    # fill username/password selectors from config
    # click submit only
    # wait for success_text in page content (timeout from config)
    # return success | failure(reason)
```

- 选择器默认：`input[name="DDDDD"]`、`input[name="upass"]`、`input[name="0MKKey"]`（见 `元素.md`）。
- **黑名单**：不得 `click` 任何 `text=注销`、`logout`、或 name/id 含 logout 的元素。
- 超时、填表失败、未出现成功文案 → `LoginResult.fail(reason)`。

### `main.py`

- `once` 在 `need_portal_login` 时调用 `asyncio.run(portal.login(...))`。
- 成功 → 调 M04 成功通知；失败 → 调 M04 失败通知 + paused（M04 实现前可先 print）。

### Playwright 安装

- `playwright install chromium` 写入 README；CI 可跳过。

## 验收标准

- [ ] 在 CAUC-WIFI 且未登录状态下，`python -m wificauc.main once` 能自动完成登录，终端或日志显示 success。
- [ ] 登录后浏览器关闭，进程退出；用户可访问外网（手动 `curl https://www.baidu.com` 等）。
- [ ] 页面出现「您已经成功登录」或 `success_text` 匹配。
- [ ] 代码审查 / 测试：无对「注销」元素的 click 调用。
- [ ] **禁止**在自动化测试中点击注销（人工测试时也勿点）。
