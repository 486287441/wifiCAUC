# M04 — 通知与失败熔断

**技术依据**：见 `plan/技术方案.md` §1（osascript）、§4.4、§5（`notify`、`notify_brief`）。

**依赖**：M01–M03 完成。

## 目标

成功/失败时发送 macOS 通知；失败后写入 `state/paused`，停止自动重试直至用户 `resume`。

## 实现要点

### `notify.py`

- `notify_success()`：`display notification "已成功登录" with title "CAUC 校园网"`。
- `notify_failure(reason: str)`：标题「登录失败」，副标题截断 reason。

### `state.py`

- `set_paused(reason: str)`：写 `state/paused`（内容可为 reason + 时间）。
- `clear_paused()`：`resume` 子命令删除该文件。
- `is_paused() -> bool`：`run` 循环开头检查。
- `write_last_run(result: str)`：`state/last_run.json`。

### `main.py` 子命令

| 命令 | 行为 |
|------|------|
| `run` | 循环；若 paused 则只 sleep |
| `resume` | 清除 paused，立即跑一轮 |
| `status` | 打印 paused、last_run、当前 SSID |

### 与 M03 衔接

- 登录成功 → `notify_success` + `last_run=success`。
- 登录失败 → `notify_failure` + `set_paused` + `last_run=fail`。

## 验收标准

- [ ] 故意错误密码：`once` 后收到失败通知，且生成 `state/paused`；再次 `once` 不尝试登录（或 `run` 不触发 portal）。
- [ ] `python -m wificauc.main resume` 后 paused 清除，可再次尝试。
- [ ] 登录成功：收到简短成功通知；**不**写 paused。
- [ ] `status` 能显示当前是否在熔断、上次结果。

### 第 1 步

实现 `notify.py`、`state.py`，接入 M03 成功/失败分支。

### 第 2 步

用户回复 **通过** 后进入 M05。
